## Investment Portfolio Simulator (Monte Carlo)

An application that simulates the future value of an investment portfolio using the Monte Carlo method and Geometric Brownian Motion (GBM).

## Features

- Simulation of a one-dimensional portfolio and multiple correlated assets.
- Cholesky transformation for generating correlated random variables.
- Interactive visualization interface using React and Recharts.
- High-performance Python backend (FastAPI + NumPy) with full linear algebra vectorization.
